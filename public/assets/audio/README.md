# Audio

The homepage chant player ("Chant" button, top-right) plays the file below.
**It is currently missing — add it here and the player works automatically:**

- `chant.mp3` (required) — a Gregorian chant recording, looped.
- `chant.ogg` (optional) — same audio in Ogg Vorbis, for broader browser support.

Tips:
- Use a **public-domain / Creative Commons** recording (e.g. Wikimedia Commons,
  the Internet Archive, or a recording you have rights to). Avoid copyrighted tracks.
- Keep it reasonably small (a 2–5 min loop, ~1–4 MB) so it streams quickly.
- If the file is absent, the chant button hides itself automatically — no broken UI.
